Shared Administrator Edits

Shared editing is not connected. This dashboard is read-only. No employee changes are saved or transmitted from this page.

The existing employee pages save locally and transmit task snapshots. They do not load administrator changes. Editing a report here would not update those pages.

Shared editing requires each employee page to load its shared record by PSN and save through an authenticated service. That service must enforce administrator permissions and prevent older records from overwriting newer changes.

Approved Position Description Tasks

Place a file named employee-catalogs.json beside this dashboard to enable comparisons between approved tasks and reported work.

Replace the example identifiers and task names below with each employee’s actual PSN, position description, and complete approved task list. 

{
  "employees": {
    "EMPLOYEE_PSN": {
      "pd": "POSITION_DESCRIPTION_ID",
      "tasks": [
        "Exact approved task name",
        "Another approved task name"
      ]
    }
  }
}

Without an approved catalog, reported hours and Other descriptions remain available, but tasks with no reported use cannot be identified.

Reporting Limitations

The existing workflow submits cumulative task lists without an explicit reporting-week identifier. This dashboard groups tasks by their actual task dates and selects the latest snapshot for each employee and week.

A submission that removes every task from a week cannot communicate that deletion through the current format. Explicit reporting-week identifiers and shared record versions are needed for reliable corrections and deletions.

Minutes and hours describe reported time, not performance ratings. Verify task catalog completeness and reporting coverage before making position description decisions.
