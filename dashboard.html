PD Number Matching

Reports and approved tasks are matched by pd, the PD number shown in parentheses on the employee page. Names are display information; correcting a name does not split the position history.

The latest saved report supplies the employee name management sees. Employees must submit or save shared changes and management must refresh after the updated data is published. Typing a name alone does not publish it.

Reports without a PD number are excluded and counted in the loading status. Add verified PD numbers to historical records before using their totals.

Each PD represents one combined history. Pages sharing a PD are combined, including their weekly snapshot replacement behavior.

Approved Task Catalog

Keep employee-catalogs.json beside this dashboard. Include one entry per PD, its section, approved tasks, and optionally its page filename. The name may be blank until a report is submitted.

Administrator Changes and Recording

Updated employee test pages save their full tracker state directly to GitHub when Save Shared Changes succeeds. GitHub commit history records the account used and file changes.

Employees can load those changes by opening the updated page or selecting Load Shared Version. Unsaved drafts require review before they are replaced.

The token-based test uses repository write permissions. It does not provide separate employee and supervisor roles. Cloudflare integration is not included in this HTML.

Reporting Behavior

For employees with full shared saves, the latest appended full state replaces earlier snapshots. This prevents old reports from bringing back removed tasks.

For employees still using the original workflow, the dashboard uses the latest snapshot containing tasks for each employee and task week. That original format cannot reliably represent removing every task from a week.

If an original workflow report appears after a full shared save for the same employee, the dashboard stops the refresh and explains the conflict.

Refresh reads the published data.json file. Repository changes must be available on the website before they appear here.

Reported time supports management review; it is not a performance rating. Confirm reporting completeness, task catalog accuracy, and recurring work before changing a position description.
